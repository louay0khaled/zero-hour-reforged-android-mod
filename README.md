## التثبيت

1. حمّل `ZeroHourReforged.apk` من [صفحة الإصدارات](https://github.com/louay0khaled/zero-hour-reforged-android-mod/releases).
2. ثبّته — التثبيت فوق أي إصدار سابق يحافظ على بياناتك وإعداداتك.
3. افتح التطبيق واختر مجلد لعبة Zero Hour الأصلية على هاتفك (التطبيق يبحث عنه تلقائيًا أيضًا).
   تحتاج نسختك القانونية من ملفات اللعبة — هذا المشروع لا يتضمّن أي أصول من اللعبة.
4. اختر اللغة ومعيار الرسومات من المشغّل، واضغط «تشغيل اللعبة».

بياناتك تعيش في مجلد خاص بالتطبيق `ZeroHourReforged/` على ذاكرة الهاتف — حفظك وإعداداتك تبقى حتى لو حذفت التطبيق وأعدت تثبيته.

## المزايا

- **المحرك الحقيقي** — Reforged 4.0.0 مبنيّ أصلًا لأندرويد 64-بت؛ محاكاة 60 تحديثًا/ثانية مثل الويندوز تمامًا، ومباريات كاملة حتى النصر مُختبَرة على هواتف ضعيفة مثل Redmi 14C.
- **تحكّم لمسي كامل** — تحديد باللمس والسحب، كاميرا بإصبعين، أوامر بالضغط المطوّل، أزرار أوضاع (هجوم قسري، نقاط مسار، انتشار، تشكيلات)، وعمود جيش: مجموعات تحكّم 0–9 واختيار الكلّ حسب النوع (الشاشة / الخريطة / الطائرات / الحوّامات / القوات البرية).
- **رسوم بمستوى الويندوز** — على الهواتف القوية: توهّج (Bloom)، تنعيم حواف (FXAA)، حدّة (Sharpen)، إطباق محيطي (AO)، ضباب (Haze) وإضاءة لكل بكسل. من المشغّل بأربعة معايير: ضعيف / متوسط / قوي / خارق. الهواتف الضعيفة (مثل Mali-G52) تأخذ ملفًا خفيفًا تلقائيًا كي تبقى اللعبة سلسة.
- **عربي كامل داخل اللعبة** — ترجمة كاملة تشمل إضافات Reforged نفسها، بخط «ثمانية» — إضافة إلى الإنجليزية والتركية والألمانية والأوكرانية والروسية والفرنسية. واجهة المشغّل بـ13 لغة.
- **لعب شبكي محلي (LAN)** — مكدّس شبكة اللعبة الأصلي بين أجهزة أندرويد. (اللعب عبر الإنترنت واللعب المشترك مع الويندوز هدف الإصدار 1.31.)
- **مشغّل نظيف** — ثلاث صفحات (الرئيسية / الإعدادات / المساعدة وحول)، سجلّ تشغيل تلقائي مع مفتاح إيقاف، وتنبيه عند توفّر تحديث. مجاني وبلا إعلانات.

# Zero Hour Reforged — on Android (English)

**The real Reforged engine, in full, on your phone** — *Command & Conquer: Generals — Zero Hour*
running [Reforged 4.0.0](https://github.com/olcayseygan/CnCGeneralsZH-Reforged) natively on Android:
the same engine, the same 60-updates-per-second simulation as Windows, the same data — with touch
controls designed for the game from scratch, full in-game Arabic, and a Windows-level graphics
layer on strong phones.

> This is not a data mod on top of someone else's engine: the Reforged engine itself is compiled
> and built specifically for Android (arm64).

### [⬇️ Download the latest release](https://github.com/louay0khaled/zero-hour-reforged-android-mod/releases/latest)

## Install

1. Download `ZeroHourReforged.apk` from the [Releases page](https://github.com/louay0khaled/zero-hour-reforged-android-mod/releases).
2. Install it — installing over any previous version keeps your data and settings.
3. Open the app and pick your original Zero Hour game folder on the phone (the app also auto-scans for it).
   You need your own legally owned copy of the game files — this project ships **no game assets**.
4. Choose the language and a graphics preset in the launcher, and press **Play**.

Your data lives in the app's own `ZeroHourReforged/` folder on shared storage — saves and settings
survive even an uninstall/reinstall.

## Features

- **The real engine** — Reforged 4.0.0 built natively for 64-bit Android; 60 updates/second simulation exactly like Windows, with full matches played to victory on weak phones such as the Redmi 14C.
- **Full touch controls** — tap and drag selection, two-finger camera, long-press orders, mode buttons (force attack, waypoints, scatter, formations), and an army column: control groups 0–9 plus select-all-by-type (screen / map / planes / helicopters / ground).
- **Windows-level graphics** — on strong phones: bloom, FXAA, sharpen, ambient occlusion, haze and per-pixel lighting, via four launcher presets (Low / Medium / High / Ultra). Weak GPUs (e.g. Mali-G52) automatically get a light profile so the game stays smooth.
- **Full in-game Arabic** — a complete translation including Reforged's own additions, in the Thmanyah typeface — plus English, Turkish, German, Ukrainian, Russian and French. The launcher speaks 13 languages.
- **LAN multiplayer** — the game's original LAN stack between Android devices. (Online play and cross-play with Windows are the goal of v1.31.)
- **A clean launcher** — three pages (Home / Settings / Help & About), an automatic run log with an off switch, and update notifications. Free, no ads.
